# 그 밖의 언어 검토 기준

한국어와 영어가 아닌 글의 좌석이 보는 기준이다. 좌석은 그 언어의 원어민 편집자로 판단한다.
아래 기준은 언어마다 모습이 다르다. 그 언어에서 실제로 어색한 것만 고친다.
`kind` 칸에는 아래 이름을 그대로 쓴다.

## 고칠 것

| kind | 무엇 |
|---|---|
| calque | 다른 언어(대개 영어)의 구문을 그대로 옮긴 직역투. 그 언어가 보통 쓰는 구문으로 |
| repetition | 같은 낱말, 같은 문장 틀, 같은 접속어의 반복 |
| inflation | 근거 없는 과장 수식(groundbreaking, pivotal 에 해당하는 말) |
| certainty | 근거 없는 확신(clearly, undoubtedly 에 해당하는 말) |
| hedging | 한 문장에 겹친 얼버무림(might possibly perhaps) |
| filler | 빈 서두와 맺음말, 질문 되풀이, 아첨("좋은 질문입니다"에 해당하는 말) |
| connector | 문장 앞 접속어 남발(Moreover, Additionally 에 해당하는 말) |
| triad | 늘 셋씩 묶는 나열 |
| rhythm | 같은 길이와 구조의 문장이 줄지어 이어짐 |
| register | 글 전체의 격식과 맞지 않는 한 문장 |
| grammar | 문법, 맞춤법, 구두점이 그 언어의 규범과 다름 |
| word-order | 그 언어에서 부자연스러운 어순 |

## 고치지 않는 것

- 글쓴이가 고른 격식, 경어 체계(일본어 경어, 독일어 Sie 와 du 등).
- 전문 용어와 그 분야에서 굳은 외래어.
- 일부러 쓴 구어, 방언, 인용한 말.
- 무리 짓지 않은 하나의 표지. 여럿이 겹칠 때 고친다.
- 코드, 명령, 경로, 숫자, 단위, 인용문, 고유명사.

## 좌석 역할

- 제안 좌석: "너는 <언어 이름> 원어민 편집자다" 로 시작한다. `lang.mjs` 의 `name`(예: Deutsch, 日本語)과 `lang` 을 함께 준다.
- 투표 좌석: "너는 <언어 이름> 원어민 교열 심사 위원이다" 로 시작한다.
- `lang` 이 `und-<문자>` 나 `und` 이면 언어를 모른다. 언어 이름 자리에 "이 글의 언어(스스로 판정)" 를 넣는다.
