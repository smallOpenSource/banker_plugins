# 한국어 검토 기준

한국어 글의 좌석이 보는 기준이다. 어색한 문장이 AI 티를 만든다. 뜻은 그대로 두고 문장만 자연스럽게 고친다.
`kind` 칸에는 아래 이름을 그대로 쓴다.

## 고칠 것

| kind | 무엇 | 원문 | 고친 글 |
|---|---|---|---|
| 번역투 | 영어 구문을 옮긴 표현. "~에 대해", "~를 통해", "~하는 것이 가능하다", "~에 있어서", "~를 가지다", "~로부터" | 회의를 가졌다. 이 방법을 통해 비용을 줄이는 것이 가능하다 | 회의를 했다. 이 방법으로 비용을 줄일 수 있다 |
| 피동 | 이중 피동("되어지다", "보여지다"), 행위자가 분명한데 쓴 피동, "~에 의해 ~되다" | 설정이 사용자에 의해 변경되어진다 | 사용자가 설정을 바꾼다 |
| 명사나열 | 명사 넷 이상이 조사 없이 이어짐, "~의" 연쇄 | 사용자 계정 권한 설정 변경 절차 | 사용자 계정의 권한 설정을 바꾸는 절차 |
| 무생물주어 | 사물이 사람에게 무엇을 시키거나 보여 주는 문장 | 이 결과는 우리에게 방향을 보여 준다 | 이 결과를 보면 방향이 보인다 |
| 대명사 | "그것", "그녀", "그들" 남용, 한국어가 생략하는 주어를 되풀이 | 그것은 그것의 장점이 있다 | 장점이 있다 |
| 복수 | 필요 없는 "-들" | 많은 사람들이 여러 문제들을 겪는다 | 많은 사람이 여러 문제를 겪는다 |
| 접속사 | 문장 앞의 "또한", "그리고", "따라서", "이를 통해" 반복 | 또한 A 다. 또한 B 다. 따라서 C 다 | A 다. B 도 그렇다. 그래서 C 다 |
| 과장 | 근거 없는 "획기적", "혁신적", "완벽한", "매우 중요한" | 획기적인 변화를 가져온다 | 크게 바뀐다(원문에 근거가 있을 때만 정도를 남김) |
| 단정 | 근거 없는 "분명히", "확실히", "반드시" | 분명히 더 빠르다 | 더 빠르다 |
| 상투구 | 빈 서두와 맺음말. "결론적으로", "도움이 되었기를 바랍니다", "~라고 할 수 있다" | 결론적으로 이는 중요하다고 할 수 있다 | 이는 중요하다 |
| 기계적병렬 | 늘 셋씩 묶는 나열, 같은 틀의 문장 반복 | 빠르고, 쉽고, 강력하다 | 원문이 둘을 말하면 둘만. 내용은 줄이지 않는다 |
| 리듬 | 같은 길이와 같은 어미("~합니다.")가 줄지어 이어짐 | 짧은 문장 다섯이 모두 "~합니다." | 둘을 잇거나 어미를 바꿈. 존대 수준은 그대로 |
| 접미사 | "~적", "~화", "~성" 남용 | 효율적인 방식으로 체계화한다 | 효율 있게 정리한다 |
| 영어병기 | 쉬운 한국어가 있는데 괄호 영어를 덧붙임 | 사용자(user)의 요청(request) | 사용자의 요청 |
| 맞춤법 | 맞춤법, 띄어쓰기 | 할수있다 | 할 수 있다 |
| 어순 | 수식어가 꾸미는 말과 멀리 떨어짐 | 빠르게 어제 만든 기능을 고쳤다 | 어제 만든 기능을 빠르게 고쳤다 |

## 고치지 않는 것

- 존대 수준(합니다체, 해요체, 한다체)과 개조식 형식. 글쓴이가 고른 형식이다.
- 전문 용어와 업계에서 굳은 외래어(캐시, 커밋, API). 낯선 번역어로 바꾸지 않는다.
- 공문서, 법률, 계약 문장의 정해진 표현.
- 일부러 쓴 구어, 사투리, 인용한 말.
- 한 번 나온 "또한", 한 번 쓴 피동처럼 무리 짓지 않은 하나의 표지. 여럿이 겹칠 때 고친다.
- 코드, 명령, 경로, 숫자, 단위, 인용문, 고유명사.
