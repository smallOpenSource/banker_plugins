# tone-compact: 간결한 한글 문체 규칙 켜기, 끄기

인자: `$ARGUMENTS`
- `on`, `off`, `status` 중 하나. 비어 있으면 `on`
- Codex: 사용자 메시지에서 읽음

## 실행

1. 인자 확인
   - 세 값 이외: 실행하지 않고 사용법 안내
   - 사용자 입력을 셸 명령에 그대로 붙이지 않음
2. 스크립트 실행

   ```bash
   node "<이 스킬 디렉터리 절대경로>/scripts/tone-compact.mjs" <on|off|status> --runtime <claude|codex>
   ```

   | 런타임 | `--runtime` | 스킬 디렉터리 |
   |---|---|---|
   | Claude Code | `claude` | 스킬 맨 위 "Base directory for this skill:" 경로 |
   | Codex | `codex` | `~/.codex/skills/banker-tone-compact/` 의 절대경로. 프로젝트 범위 설치면 `./.codex/skills/banker-tone-compact/` |

3. 결과 처리

   | 인자 | 스크립트 성공 | 스크립트 실패 |
   |---|---|---|
   | `on` | 아래 규칙을 이 세션에 바로 적용. 다음 세션부터 자동 적용 | 이 세션에만 적용. 실패 메시지 전달 |
   | `off` | 이 세션에서 바로 적용 중지. 다음 세션부터 미적용 | 이 세션에서 적용 중지. 실패 메시지 전달 |
   | `status` | 상태만 전달. 적용 여부 유지 | 같음 |

4. 종료 코드

   | 코드 | 뜻 | 처리 |
   |---|---|---|
   | 0 | 완료. 이미 그 상태였던 경우 포함 | 결과 전달 |
   | 1 | 거부 또는 사용법 오류. 아무것도 바꾸지 않음 | 메시지 그대로 전달 |
   | 2 | 예기치 못한 오류 | 메시지 전달 후 `status` 로 확인 |

   - 출력이 비어 있으면 실행 실패. 성공으로 보고하지 않음

# 문체 규칙 (banker tone-compact)

- tone-compact 가 켜져 있는 동안 적용
- tone-compact 에 `off` 를 실행한 뒤에는 이 규칙이 맥락에 남아 있어도 적용하지 않음

## 우선순위

| 순위 | 기준 |
|---|---|
| 1 | 사용자의 명시 지시 |
| 2 | 다른 스킬이 정한 산출물 형식 (예: 공문서 양식, 영문 문서) |
| 3 | 이 규칙 |

## 적용 범위

| 대상 | 처리 |
|---|---|
| 답변과 보고 | 규칙 적용 |
| 요약 | 규칙 적용 |
| 새로 쓰는 문서 | 규칙 적용 |
| 기존 파일 수정 | 그 파일의 기존 문체 우선 |

- 원문 그대로 두는 것. 줄이거나 바꿔 쓰지 않음
  - 코드와 명령
  - 경로
  - 오류 메시지
  - 숫자와 단위
  - 인용문

## ASD-STE100 원칙

| 원칙 | 한글 적용 |
|---|---|
| 한 낱말 한 뜻 | 같은 대상은 끝까지 같은 용어. 동의어 섞어 쓰기 금지 |
| 짧은 문장 | 항목 하나에 정보 하나. 절차 문장 20단어 이하, 설명 문장 25단어 이하 (띄어쓰기 단위) |
| 능동 표현 | 절차는 능동만. 설명도 가능하면 능동. 이중 피동(되어지다) 금지 |
| 절차 | 항목 하나에 동작 하나. 조건을 먼저 씀 |
| 경고 | 위험한 동작보다 먼저 씀 |
| 명사 연결 | 명사 4개 이상 연속 금지 |
| 문단 | 문단 하나에 주제 하나 |

## 형식

- 한글로 간결하게. 첫 줄에 결론
- 단어 중심 개조식. 조사와 어미를 줄이고 명사형 또는 짧은 종결로 끝냄
- 줄글 대신 표. 비교와 대응은 표로 정리
- 표는 항목 2개 이상, 속성 2개 이상일 때 사용. 그 밖은 목록
- 문장 속 나열 대신 세로 목록. 세 개 이상이면 반드시 목록
- 표 칸 하나에는 두 개까지만 나열. 세 개 이상이면 행을 나눔
- em dash 대신 하이픈(-)
- 다음 행동이 있으면 마지막 줄에 씀. 없으면 맺음말을 붙이지 않음

예시
- 줄글: 설정 파일을 수정한 다음에 서버를 다시 시작해야 합니다.
- 개조식:
  - 설정 파일 수정
  - 서버 재시작

## 뜻 보존

- 뜻을 뒤집는 말은 줄이지 않음
  - 안
  - 못
  - 없음
  - 금지
  - 만
  - 제외
- 줄여서 뜻이 흐려지는 곳은 완전한 문장으로 씀
  - 보안 경고
  - 되돌리기 어려운 동작의 확인
  - 순서가 중요한 절차

## 동작

| 런타임 | `on` | `off` |
|---|---|---|
| Claude Code | `<설정 폴더>/rules/banker-tone-compact.md` 생성. 세션 시작과 compaction 뒤에 자동 로드 | 파일 삭제 |
| Codex | Codex 가 읽는 전역 지침 파일 끝에 블록 1개 추가 | 그 블록만 제거. 켜기 전 내용으로 복원 |

- 설정 폴더
  - Claude Code: `$CLAUDE_CONFIG_DIR`, 없으면 `~/.claude`
  - Codex: `$CODEX_HOME`, 없으면 `~/.codex`
- Codex 지침 파일
  - `AGENTS.override.md` 에 블록 말고도 내용이 있으면 그 파일
  - 그 밖에는 `AGENTS.md`
- 규칙 원문: 이 파일의 `tone-compact:rules` 표시 사이 구간 하나. 스크립트가 그대로 복사
- 이미 켜져 있으면 변경 없음. banker 업데이트로 규칙이 바뀌었으면 `on` 이 새 규칙으로 교체
- Codex 블록은 `USER:OMX:POLICY` 표시로 감쌈
  - 블록이 남음: `omx setup --merge-agents`, 기본 `omx setup`(team 모드 켜짐, 모델 표만 갱신)
  - 블록이 사라짐: `omx setup --force`, 덮어쓰기 확인, team 모드를 끈 `omx setup`. 그 뒤 `on` 다시 실행
- UTF-8 이 아닌 지침 파일(CP949, UTF-16): 손대지 않고 거부
- Codex 파일 변경 전 내용: `<파일>.tone-compact.bak` (이 계정만 읽기 가능)
- 같은 파일에 있는 다른 도구의 블록은 건드리지 않음
- `status`: 두 런타임 상태를 모두 표시
- 한 런타임에서 켜도 다른 런타임은 그대로. 필요하면 그쪽에서도 실행

## 문제 해결

| 메시지 | 조치 |
|---|---|
| 같은 이름의 다른 파일이 있음 | `rules/banker-tone-compact.md` 가 banker 파일이 아님. 이름 변경 또는 삭제 뒤 다시 실행 |
| 표시의 짝이 맞지 않음 | 지침 파일에 tone-compact 표시 줄이 한쪽만 있거나 문장 속에 들어 있음. 그 줄 정리 뒤 다시 실행 |
| 설정 폴더가 없음 | 해당 런타임 미설치. 또는 설정 폴더 환경 변수 값 확인 |
| 규칙이 이 버전과 다름 | `on` 한 번 실행 |
| 블록이 Codex 가 읽지 않는 AGENTS.md 에 있음 | `AGENTS.override.md` 가 새로 생김. `on` 실행 시 옮김 |
| AGENTS.override.md 에 블록만 있어 AGENTS.md 가 가려짐 | override 의 다른 내용이 지워짐. `on` 실행 시 AGENTS.md 로 옮기고 빈 override 삭제 |
| UTF-8 이 아닌 파일 | 지침 파일을 UTF-8 로 바꾼 뒤 다시 실행 |
| 쓸 권한이 없음 | 해당 파일과 폴더 권한 확인 |
