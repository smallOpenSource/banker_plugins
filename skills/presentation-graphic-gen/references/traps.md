# 함정과 대처

| 함정 | 일어나는 일 | 이 스킬의 대처 | 지키는 시험 |
|---|---|---|---|
| 문자열 값 보간 | `background-position` 같은 문자열 값을 보간하면 단위가 튀어 밑줄이 글에서 날아감(다른 엔진에서 실제로 겪은 일) | 움직이는 값은 `opacity`, `translate`, `scale`, `rotate` 숫자뿐. 그 밖은 빌드 오류 | 키프레임 속성과 값 모양 검사, 금지 속성 오류 |
| 같은 속성의 여러 애니메이션 | WAAPI 에서 뒤에 시작하는 애니메이션의 `fill: both` 가 시작 전에도 앞 애니메이션을 덮음 | 요소와 채널마다 구간을 키프레임 트랙 하나로 합치고(구간 사이는 유지 키프레임), 겹치는 구간은 빌드 오류 | 세 단계에 걸쳐 같은 채널을 움직이는 예시 숫자의 경계값, 단순 합성의 실패를 보이는 대조 시험 |
| 콜백으로 바꾼 상태 | `finish`, `ready` 콜백의 상태 변경은 건너뛰거나 되돌릴 때 생기지 않음 | 화면 상태는 키프레임에서만. 애니메이션은 재생하지 않고 `currentTime` 으로만 맞춤 | 엔진 소스 검사, 장면 소스 검사 |
| 시계와 무작위 | 열 때마다 화면이 다름 | 장면에서 금지, `s.rand(seed)` 만 | 장면 검사 시험 |
| 글꼴이 늦게 옴 | 밑줄 폭을 잰 뒤 글꼴이 바뀌면 어긋남 | `document.fonts.ready` 를 기다린 뒤 타임라인을 만듦. 글꼴은 HTML 안에 있음 | 글꼴 대기 시험 |
| 처음 깜빡임 | 타임라인이 생기기 전 한순간 보이는 요소 | 타임라인이 생기기 전 무대는 CSS 로 숨김, 장면은 `opacity: 0` 에서 시작 | 대기 중 화면이 한 색인지 보는 시험 |
| 함께 움직여야 할 것 | 글과 밑줄을 따로 움직이면 사이가 벌어짐 | 함께 움직일 것은 부모 층(`.layer`) 하나만 움직임 | 층이 미끄러지는 동안 밑줄과 글의 거리가 같은지 보는 시험 |
| 손으로 정한 장식 | 고정 폭 막대가 글 아래에서 밑줄처럼 보이나 글과 맞지 않음 | 밑줄은 `s.underline`, 형광은 `s.mark`, 취소선은 `s.strike`. 그 밖의 얇은 막대가 글 바로 아래 있으면 그 글의 밑줄로 보고 검사 | `decorations` 게이트와 그 양방향 시험 |
| 따로 움직이는 조각 | 한 도형을 조각 여러 개로 나눠 따로 움직이면, 화면 배율과 기기 픽셀 비율에 따라 조각이 어긋남. 옛 강조 테두리(`.ring`)는 1px 조각 네 개를 100배 넘게 늘려 만들었다. GPU 로 그리는 Chrome 에서 픽셀 비율 1.25 면 변이 0.83배로 짧아져 모서리가 열렸고 1.5 면 길게 삐져나옴. 헤드리스 브라우저와 픽셀 비율 1 에서는 보이지 않음 | 규칙: 한 도형은 요소 하나로 그린다(CSS 테두리와 `border-radius`). 1~2px 요소를 늘려 크기를 만들지 않는다. 조각으로 그려야 하면(`s.box`, `s.connector`) 조각마다 처음부터 끝 크기로 두고 `scale` 0 에서 1 로만 그린다. 강조는 `s.focus` 의 테두리 하나 | `decorations`, `decorations-played`(1227x785, 픽셀 비율 1.5, 키로 재생한 가운데와 끝) 게이트와 그 양방향 시험 |
| Chromium 의 H.264 | Chromium, Playwright 의 chromium 은 H.264 를 풀지 못함 | PPTX 영상 연속성 게이트가 SKIP(통과 아님). Chrome 이나 Edge 로 다시 돌림 | `verify` 의 SKIP 줄 |
| 편집 PPTX 의 그림 대체 | 그림, SVG, 회전, 그라데이션, 빗금은 PowerPoint 도형으로 그릴 수 없음 | 그 요소만 투명 바탕에 잘라 낸 그림으로 바꿔 넣고 목록을 냄 | `pptx-edit` 출력의 `fallback` 줄 |
| PPTX 글꼴 | 글꼴 파일을 넣지 않음 | 테마 글꼴만 지정(Latin Noto Sans, East Asian Noto Sans KR). 보는 PC 에 두 글꼴이 있어야 같은 줄바꿈 | 보고에 적음 |
| 덮어쓰기 | 지난 회차가 사라짐 | 모든 도우미가 이미 있는 파일과 비어 있지 않은 출력 폴더(`check-...`, 녹화, `--frames`, PowerPoint PNG)에 작업 전 종료 코드 2 로 끝남. `--force` 는 허락 뒤에만 | 덮어쓰기 시험 |
| vendor 손상 | 다른 바이트로 실행 | `build.mjs`, `make.mjs` 는 시작할 때 vendor 파일 전부를 원본 sha256 과 대조하고, 하나라도 다르면 작업 전에 종료 코드 3. 다른 도우미도 읽는 파일이 다르면 3 | vendor 변조 시험(글꼴, wasm, h264, PptxGenJS 각각) |
| snap Chromium | `/tmp` 의 프로필과 덱을 못 봐 브라우저가 뜨지 않거나 빈 화면 | 프로필은 홈 아래, 못 읽는 덱은 까닭과 `CHROME` 안내로 종료 코드 2(`offline-install.md`) | 판단 함수 단위 시험 |
| 디버깅 포트 | 같은 PC 의 다른 사용자가 열린 포트로 브라우저를 조종 | 포트를 열지 않고 브라우저의 파이프(`--remote-debugging-pipe`)로만 말함 | `cdp.test.mjs` |

## 같은 채널을 여러 단계에서 움직이는 법

```js
's4-1'(s) { s.bigNumber('num', 'sub'); },                                   // y 16 에서 0, 투명도 0 에서 1
's4-2'(s) { s.move('num', { y: -140, scale: 0.4 }, { dur: 0.7 }); s.dim('num', { at: 0.5 }); },
's4-3'(s) { s.move('num', { x: 1000, y: -100, scale: 0.6 }, { at: 0.4 }); s.tween('num', null, { opacity: 1 }, { at: 0.6 }); },
```

- 각 구간의 시작값은 그 앞 구간의 끝값이다. 어느 시각으로 건너뛰어도 같은 값이 나온다.
- 한 단계 안에서 같은 채널을 두 번 움직이려면 앞 것이 끝난 뒤(`at` 을 끝 시각 이후로) 시작한다.
- 같은 요소에서 `y` 를 움직이는 동안 `x` 도 움직이려면 한 `move` 에 함께 넣는다(같은 `translate` 채널).

## 잘 안 되는 것

- 색 변화: 색은 보간하지 않는다. `s.accent` 처럼 다른 색 복사본의 투명도를 바꾼다.
- 크기(width, height) 변화: 처음부터 끝 크기로 두고 `scaleX`, `scaleY` 를 0 에서 1 로 그린다. 작은 조각을 크게 늘리지 않는다.
- 블러, clip-path: 쓰지 않는다. 닦아 내기는 `s.reveal`.
