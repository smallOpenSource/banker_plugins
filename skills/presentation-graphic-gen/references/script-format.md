# 대본 형식(화면/말)

사용자의 대본 초안을 이 형식으로 맞춘다. 내용은 바꾸지 않는다. `build.mjs` 가 읽는 규칙 그대로다.

## 틀

```markdown
# 발표 제목

## 1. 섹션 이름 (목표 0:30)

### 1-1
화면: 화면에 나올 첫 줄
- 둘째 줄
- 셋째 줄
[연출: 제목이 떠오르고 밑줄이 그려짐]
말:
발표자가 이 단계에서 할 말. 여러 줄도 된다. [잠시 멈춤] 같은 대괄호는 연출로 따로 모인다.

### 1-2
화면: 다음 화면
말: 한 줄이면 말: 뒤에 바로 써도 된다.

## 메모
- 번호 없는 ## 제목에서 대본이 끝난다. 그 아래는 읽지 않는다.
```

## 규칙

| 요소 | 규칙 |
|---|---|
| `# 제목` | 첫 `# ` 줄. 없으면 오류 |
| `## <n>. <이름> (목표 m:ss)` | 섹션 하나 = 장면 파일 하나(`scenes/NN.js`, NN 은 두 자리 n). 번호는 1부터 차례로. `(목표 m:ss)` 는 선택 |
| `### <n>-<k>` | 단계 하나 = 키 한 번. 단계 id 는 `s<n>-<k>`. k 는 1부터 차례로 |
| `화면:` | 화면 글. 같은 줄 뒤에 첫 줄, 다음 줄부터는 `- ` 로 시작. 단계마다 한 줄 이상 |
| `[...]` 만 있는 줄 | 연출. 화면에도 말에도 들어가지 않고 검토용 패널과 PPTX 노트에 따로 나옴 |
| `말:` | 발표자의 말. 다음 줄부터 다음 `###` 나 `##` 까지. 안의 `[...]` 는 연출로 빠짐 |
| 첫 `###` 앞의 글 | 무시(메모로 써도 됨) |
| 번호 없는 `## ` | 대본 끝 |

- 화면 줄 순서는 장면 파일의 `d.lines('s1-1')` 배열 순서다. 장면은 이 배열을 그대로 쓴다.
- 표처럼 칸이 필요하면 한 줄에 `칸 | 칸` 으로 쓰고 장면에서 `split('|')` 한다.
- 화면 글은 요점만. 말을 화면에 그대로 옮기면 빌드가 `경고: <단계>: 화면 글자의 N% 가 말과 겹칩니다` 를 낸다(글자 2개 묶음이 70% 이상 겹칠 때, 화면 글 10자 이상).

## 시간 예산

- 말의 음절 수로 어림한다. 한글 음절 하나, 영문자나 숫자 하나를 1 로 센다. 분당 290음절.
- `build.mjs` 출력 예:

```text
시간 예산 (분당 290음절)
  1. 표지  70음절  0:14 / 목표 0:20
  5. 흔한 실수  79음절  0:16 / 목표 0:15  초과
  합계  509음절  1:45 / 목표 2:00
```

- 초과 섹션은 사용자에게 알리고, 말을 줄일지 목표를 바꿀지 묻는다. 에이전트가 임의로 줄이지 않는다.

## 검토용 HTML 의 패널

- 섹션 이름, `k / N`, 단계마다 키(`1-1`), `화면:` 줄, 연출(기울임), 말.
- 타이머는 열 때마다 00:00 에서 시작하고 저장하지 않는다. 섹션 시간과 목표를 함께 보여 준다.
- 발표용 HTML 에는 패널과 말이 없다(데이터에서도 빠짐).
