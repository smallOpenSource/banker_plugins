# anti-drm: DRM 이 암호화하는 확장자 피하기

- 망분리 PC 의 DRM 은 정해진 확장자의 파일을 암호화함
- 암호화된 파일은 에이전트와 개발 도구가 읽지 못함
- 이 스킬은 그 확장자 대신 대체 확장자로 파일을 만들게 하는 규칙을 켜고 끔
- 이미 DRM 이 걸린 파일을 풀거나 변환하지 않음. 에이전트가 새로 만드는 파일의 확장자만 정함
- 조직의 보안 규정이 이 스킬의 규칙보다 우선함

인자: `$ARGUMENTS`
- `on`, `off`, `status`, `config` 중 하나. 비어 있으면 `on`
- Codex: 사용자 메시지에서 읽음

## 실행

1. 인자 확인
   - 네 값 밖: 실행하지 않고 사용법 안내
   - 사용자 입력을 셸 명령에 그대로 붙이지 않음
2. 스크립트

   ```bash
   node "<이 스킬 디렉터리 절대경로>/scripts/anti-drm.mjs" <명령> [옵션]
   ```

   | 런타임 | `--runtime` | 스킬 디렉터리 |
   |---|---|---|
   | Claude Code | `claude` | 스킬 맨 위 "Base directory for this skill:" 경로 |
   | Codex | `codex` | `~/.codex/skills/banker-anti-drm/` 의 절대경로. 프로젝트 범위 설치면 `./.codex/skills/banker-anti-drm/` |

3. 아래 인자별 절차를 따름

## 인자별 절차

### `on`

1. `status` 를 실행해 `- 설정:` 줄을 봄
2. 그 줄에 따라 실행

   | `- 설정:` 줄 | 다음 |
   |---|---|
   | `없음` | 아래 "질문" 을 한 뒤 "설정 넘기기" 대로 `on --runtime <런타임> --stdin` 실행 |
   | 파일 경로 | `on --runtime <런타임>` |
   | `올바르지 않음` | 이유를 전하고 설정을 다시 정할지 물음. 정하면 "질문" 뒤 `없음` 행과 같은 명령 실행. 그 파일은 새 파일로 바뀌고(그 자리가 폴더나 특수 파일이거나, 64KiB 보다 크거나, 읽을 수 없는 파일이면 바꾸지 않고 거부함. 링크와 하드 링크(이름이 둘 이상인 일반 파일)는 거부하지 않고 그 이름만 일반 파일로 바꾸며, 가리키던 파일은 그대로 두고 `.bak` 에 남기지 않음), anti-drm 형식이 아니면 `anti-drm.json.bak` 에 한 번 남음. 에이전트가 그 파일을 직접 지우거나 옮기지 않음 |

3. 성공하면 출력의 `적용할 규칙:` 아래 규칙을 이 세션에 바로 적용. 다음 세션부터는 자동 적용

### `off`

1. `off --runtime <런타임>` 실행
2. 성공하면 이 세션에서 규칙 적용을 멈춤
3. 설정 파일은 남음. 다시 켤 때 묻지 않음

### `status`

- `status` 를 실행하고 출력을 그대로 전달

### `config`

1. `status` 로 지금 설정을 봄
2. 지금 값을 함께 보이며 아래 "질문" 을 함
3. "설정 넘기기" 대로 `config --stdin` 실행
4. 이 런타임이 켜져 있으면 출력의 `적용할 규칙:` 아래 규칙을 이 세션에 바로 적용

## 질문

- Claude Code: `AskUserQuestion` 한 번에 세 질문
- Codex: 같은 세 질문을 한 메시지로 묻고 답을 기다림
- `config` 에서는 질문 문구에 지금 값을 넣음 (예: `지금: .txt .pdf`)

### 질문 1. 금지 확장자 (여러 개 선택)

- 문서: `.txt` `.doc` `.docx` `.hwp` `.hwpx`
- PDF와 발표: `.pdf` `.ppt` `.pptx`
- 표: `.xls` `.xlsx` `.csv`
- 직접 입력: 더할 확장자 또는 전체 목록
- 권고: 세 묶음 모두

### 질문 2. 대체 확장자 (여러 개 선택)

- `.md`: 글과 메모
- `.html`: 서식 문서와 발표 자료
- `.tsv`: 표 데이터
- 직접 입력
- 권고: 셋 모두

### 질문 3. TSV 구분자 (하나 선택)

- 질문 2 에서 `.tsv` 를 고른 경우에만 적용
- 탭(권고): 표준 TSV
- 쉼표: CSV 내용을 그대로 쓰고 확장자만 `.tsv`. 읽고 쓰는 코드에 구분자 쉼표를 명시해야 함

### 답 처리

1. 고른 묶음의 확장자와 직접 입력한 값을 합침
2. 직접 입력은 쉼표나 공백으로 나눔
3. 낱말마다 `^\.?[A-Za-z0-9]+$` 를 만족해야 함. 아니면 그 값을 보이고 다시 물음
4. 금지와 대체에 같은 확장자가 있으면 다시 물음
5. 정규화한 확장자만 넘김
   - 소문자로 바꿈
   - 앞에 점이 없으면 붙임
   - 쉼표로 이어 "설정 넘기기" 의 `deny=`, `alt=` 줄에 씀
6. 스크립트가 거부하면 그 메시지를 전하고 다시 물음

### 설정 넘기기

- 설정 값은 명령줄 인자가 아니라 표준 입력으로 넘김. 따옴표 친 heredoc 안의 글은 셸이 해석하지 않음

  ```bash
  node "<이 스킬 디렉터리 절대경로>/scripts/anti-drm.mjs" config --stdin <<'ANTI_DRM_SETTINGS'
  deny=.txt,.pdf
  alt=.md,.html,.tsv
  tsv=tab
  ANTI_DRM_SETTINGS
  ```

- `on` 은 `config` 자리에 `on --runtime <런타임>` 을 씀
- PowerShell 은 `@'` 와 `'@` 사이에 같은 세 줄을 두고 `| node "<경로>/scripts/anti-drm.mjs" config --stdin` 으로 넘김
- 넘기기 전에 heredoc 안의 줄마다 `^(deny|alt|tsv)=[a-z0-9., ]*$` 에 맞는지 확인. 하나라도 맞지 않으면 실행하지 않고 "질문" 으로 돌아감
  - "답 처리" 의 단어 검사와 겹치는 두 번째 방벽. 끝 표시(`ANTI_DRM_SETTINGS`, PowerShell 의 `'@`)는 이 꼴에 맞을 수 없어 값이 heredoc 을 일찍 닫지 못함
- 줄은 `deny=`, `alt=`, `tsv=` 를 하나씩. `tsv=` 는 대체 확장자에 `.tsv` 가 있을 때만 씀
- `--stdin` 은 입력이 끝날 때까지 기다림. 늘 heredoc 이나 파이프로 넘김

## 새 파일

- 새로 만드는 파일에 금지 확장자를 쓰지 않음. 위 표의 대체 확장자로 만듦
- 다음 파일도 같음
  - 작업 파일과 임시 파일
  - 로그와 시험 데이터
  - 셸 리다이렉션과 스크립트가 만드는 파일
  - 다른 스킬의 절차에 적힌 파일. 그 파일을 읽는 명령의 이름도 함께 바꿈

## 금지 확장자 산출물

- 대상
  - 사용자가 금지 확장자 파일을 명시해 요청함
  - 다른 스킬의 산출물이 금지 확장자임
- 처리 순서
  1. 두 가지를 알림
     - DRM 이 암호화하면 에이전트가 다시 읽지 못함
     - 함께 둘 대체 확장자 원본은 DRM 이 보호하지 않음
  2. 사용자 확인 뒤 만듦
  3. 확인받았으면 내용 원본도 대체 확장자 파일로 함께 둠. 고칠 때는 원본을 고친 뒤 다시 만듦
  4. 만든 금지 확장자 파일은 다시 읽지 않음. 검증은 원본으로 함

## 이미 있는 파일

- 금지 확장자 파일의 이름을 바꾸지 않음
- 읽은 내용이 깨진 바이너리면 DRM 이 암호화한 파일로 봄
  - 풀거나 다른 형식으로 바꾸려 하지 않음
  - 읽을 수 없다고 사용자에게 알림. 평문 사본을 요청하거나 권하지 않음
- 금지 확장자 파일을 고치기 전에 사용자에게 알림. 저장하면 암호화될 수 있음
- 도구가 이름을 정한 파일은 이름을 유지함 (예: `requirements.txt`)
  - 새로 만들어야 하면 먼저 알림
  - 대체 수단이 있으면 제안함 (예: `pyproject.toml`)
- 사용자가 요청한 프로그램의 출력 형식은 요청대로 둠. 금지 확장자를 만드는 코드면 알리기만 함

## 문제 해결

- 아래 표에서 파일을 보인다는 것은 `ls -l` 로 그 이름의 종류와 링크 대상 경로를 보이는 것이다. 링크가 아닌 일반 파일임을 본 뒤에만 내용을 연다. 심어 둔 링크가 가리키는 파일(키 등)이 세션에 오르지 않게 한다.
- `.bak` 파일(`anti-drm.json.bak`, `<파일>.anti-drm.bak`)은 내용을 열지 않고 경로만 알린다. 링크가 가리키던 파일(키 등)의 사본일 수 있다. 0.19.0 까지는 설정 파일 자리의 링크도 그 대상을 남겼다.

| 메시지 | 조치 |
|---|---|
| 설정이 없습니다 | "질문" 으로 설정을 정해 `on` 에 넘김 |
| 표준 입력에 설정 줄이 없습니다 | heredoc 이 비었음. "설정 넘기기" 대로 줄을 넣어 다시 실행 |
