# KB

knowledge base. OMC 나 OMX 위키 밖에서 사용자가 알고 있어야 할 내용을 두는 2차 위키. banker init-dir 이 만든 틀이다.

- 대상: 사용자가 직접 읽고 판단해야 하는 내용(운영 연락처 위치, 업무 규칙, 외부 시스템 사용법, 반복되는 결정의 배경)
- 에이전트용 지식은 OMC 위키(`.omc/wiki`)나 OMX 위키(`omx_wiki/`)에 둔다. 같은 내용을 두 곳에 쓰지 않는다
- 비밀값을 적지 않는다

## 색인 규칙

- 페이지 하나에 주제 하나. 파일 이름은 `<주제>.md`(소문자, 하이픈)
- 새 페이지를 만들면 아래 색인에 한 줄을 더한다: `- [제목](파일.md): 한 줄 요약`
- 페이지 첫 줄은 `# 제목`, 둘째 단락에 마지막 확인 날짜
