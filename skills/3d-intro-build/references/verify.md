# 3D 인트로 독립 검증 목록

작성자와 다른 검증 주체가 이 목록으로 판정한다. 측정할 수 있는 항목은 `verify-intro.mjs` 가 잰다. 눈으로 볼 항목은 검증자가 직접 본다.

## 1. 측정 (verify-intro.mjs)

Node 용 playwright 패키지와 Chromium 이 필요하다(`npm i -g playwright && npx playwright install chromium`, 또는 프로젝트에 `npm i -D playwright`).

```bash
node references/verify-intro.mjs http://localhost:<port>/ --out verify.json
node references/verify-intro.mjs http://localhost:<port>/ --viewports 1280x800r --out verify-reduced.json   # 움직임 줄이기
```

| 항목 | 기준 |
|---|---|
| 화면 크기 | 1280x800, 1920x1080, 860x900, 390x844 터치, 375x667 터치. 지원 언어마다 그 언어 주소로 반복 |
| 컨텍스트 | 화면 크기마다 새 브라우저 컨텍스트(재빌드 뒤 캐시 회피) |
| 패널 위치 | 화면 안, 고정 헤더 아래(`--header` 로 사이트 헤더 지정). 1px 여유 |
| 겹침 | 패널이 안내, 건너뛰기 링크, 메인화면 버튼, 장면 점과 겹치지 않음 |
| 가로 넘침 | 문서 폭이 화면 폭을 넘지 않음 |
| 콘솔 오류 | 0. CSP 거부가 있으면 정책과 `styleHash` 를 확인 |
| 대비 | 글자를 숨긴 채 패널을 찍고, 글자 줄마다 가장 나쁜 배경 픽셀 기준 4.5 이상 |
| 입력 (장면 단위 이동) | 직전 장면에서 휠 1칸과 관성 1회가 마지막 장면에 멈춤 |
| 입력 (본문이 있을 때) | 마지막 장면에서 휠, 아래 방향키, PageDown, Space, 스와이프 1회로 본문 맨 위에 섬. 위 입력 1회로 마지막 장면 복귀 |
| 버튼과 링크 | 메인화면 버튼은 마지막 장면 전에는 숨고 도착하면 보임. 누르면 본문으로 가서 포커스가 본문에 감. 건너뛰기 링크도 같음 |
| 움직임 줄이기 | 이동 시간 0. 메인화면 버튼이 마지막 장면에서 보임 |

## 2. 눈으로 보는 항목

| 항목 | 기준 |
|---|---|
| 장면의 뜻 | 장면 하나에 뜻 하나. 이야기가 인터뷰에서 정한 순서로 읽힘(예: 문제 제기, 해법, 결론) |
| 행위 주체 | 누가 무엇을 하는지 화면에서 드러남(예: 문제를 일으키는 쪽과 푸는 쪽, 제품을 쓰는 사람) |
| 표현 | 브랜드 톤에 맞음. 의도하지 않은 만화식 은유가 없음 |
| 화면 속 글자 | 깨진 글자, 뜻 없는 글자가 없음. 있으면 그 스틸이나 클립만 재생성 |
| 사물 | 사물이 엉뚱한 위치에 뜨거나 이상하게 움직이지 않음. 색이 다른 물체로 번지지 않음 |
| 이음매 | chain 은 경미한 톤 drift 까지 허용. holdFlight 는 비행 클립의 첫과 끝 프레임이 장면과 맞음 |
| 첫 이동 | 첫 장면에서 처음 움직일 때 영상이 바로 나옴(클립 미리 받기) |
| 문구 | 375px 화면에서 본문이 넘치지 않음. 유리 패널이면 본문은 한 줄에 항목 하나(권장 세 줄). CTA 는 마지막 장면에만 |
| 가로 휴대폰 | 지원 대상이면 844x390 같은 크기에서 마지막 장면 버튼이 잘리지 않음 |

## 3. 판정

- 측정 실패가 0 이고 눈으로 보는 항목에 지적이 없으면 APPROVE.
- 지적이 있으면 REQUEST CHANGES 와 함께 화면 크기, 장면 번호, 항목, 측정값을 적는다. 작성자는 그 항목만 고치고 같은 검증자가 다시 잰다.
